Project Management Application:

Technology Stack: React, JavaScript, Express.js, Node.js, MongoDB

Overview:
A web-based Project Management Application that allows users to create user accounts,
create and manage projects, organize project members, and track development tasks through user stories. 
Users can create projects, assign members, and manage a project backlog by creating, 
editing, assigning, and deleting user stories.

This application was developed using React, Express.js, and MongoDB.

Features:
 - Project Management -Create and manage projects.
 -View project - details, including name, description, and status.
 -Assign project leads and manage project membership.
 -Add and remove members from projects.
 - Prevent removal of project leads.

User Stories:
 - Create user stories associated with a selected project.
 - Define stories
 - Set story priorities: High, Medium, or Low.
 - Assign stories to project members or leave them unassigned.
 - Edit existing user stories.
 
Project Backlog
 - View user stories belonging to a selected project.
 - Track story statuses: To Do, In Progress, and Done.
 - View story descriptions, priorities, and assigned members.
